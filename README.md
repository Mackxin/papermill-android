# 卷子 PaperMill

给小学 / 初中孩子用的**练习卷生成与打印** Android App。选年级 → 选题型组合 → 实时预览 → 补满一页 → 打印出来。题目全部离线生成，数据只存在本机。

搭配奔图 M1（或任何支持 AirPrint / Mopria 的打印机）在家打印；不在同一 WiFi 时导出 PDF 走「奔图云打印」小程序远程打印。

---

## 核心流程

```
选年级 / 科目（可多选交叉）
   → 选预设卷 或 进「自由组合」自己配题
   → 实时预览第 1 页 + 末页填充率
   → 生成试卷，左右滑动看每一页 A4 预览
   → 空白太多？点「补满这一页」或「加 N 题」（保证不多印一张纸）
   → 竖版 / 横版随时切换，立即重排
   → 系统打印 / 保存 PDF / 分享 PDF
```

**「打印出完整的一页纸」是硬目标**：自动补题带硬约束 —— 逐轮试排，只保留「不增加正文页数且末页填充率最高」的那一版；预览页手动加题也会先试排，放不下自动减量并提示。

## 界面与手势

- **四个页签可左右滑动**：卷子 / 打印纸 / 错题本 / 更多放进 `HorizontalPager`，手指横滑即可整页切换，底部 dock 高亮跟着走；点 dock 时是滑过去而不是硬切。
- **预览页翻页也是滑动**：A4 页面用 `HorizontalPager` 承载，横滑翻页，下方圆点指示器（选中拉长）可点着跳页，并有「第 X / Y 页」文字。
- **返回键 App 内逐层退**：预览 → 回到进入前的来源页（出卷 / 历史 / 错题本 / 打印纸各自记着从哪来）；子页面 → 回上一级；只有停在首页再按一次才退出，且第一次会提示「再按一次返回即退出」，2 秒内不再按就自动复位，不会一按就掉回桌面。
- **视觉**：渐变主色（`#6C7BFF → #9A5CF6`）+ 薄荷绿点缀，冷调浅雾灰底、白卡 22dp 大圆角 + 柔和投影（去掉描边）、胶囊 chip、渐变主按钮、首页渐变 Hero 卡。底部是**悬浮胶囊 dock**，不再是贴边的一条横线。全局没有图片资源，图标全部走 Material 矢量。

## 自由组合（最大化的自定义出题）

「自由组合」是这款 App 的核心特色 —— 题不由我们限死，由你自己配。首页 Hero 卡下面就是它的入口。

| 能力 | 说明 |
|---|---|
| 智能配比 | 一键按科目分组抽样，每科最多 2 种题型，客观题 8 道 / 需书写过程题 3 道，总量封顶 32 题 |
| 换一套 | 同配置重抽题目（换种子），不影响题量 |
| 清空 | 一键清空所有题型，从零开始挑 |
| 逐题型调量 | 每种题型独立 `−5 / −1 / ＋1 / ＋5`，红色叉直接移除 |
| 题型库 | 该年级可用的全部题型（当前 38 种），关键字搜索 + 按科目筛 chip |
| 一键入库 | 题型库每条右侧「＋10」，不离开列表就能把题型加进组合 |
| 卷面细调 | 纸张方向、自动补满 / 严格按题量、难度、客观题栏数、答案页、姓名栏、自定义标题 |

## 打印奔图 M1

**在家（同一 WiFi）**：手机装「奔图打印」App，或在 系统设置 → 打印 里启用 Mopria 打印服务 → App 里点「系统打印」→ 选奔图 M1 → 纸张选 ISO A4（选横版时打印框自动匹配 A4 横向）。

不需要奔图 SDK：M1 支持 AirPrint / Mopria，Android 自带 `PrintManager` + `PrintDocumentAdapter` 直接送 PDF 即可。

**在外面（远程）**：点「分享」把 PDF 发到微信 → 长按 PDF → 用其他应用打开 → 「奔图云打印」小程序 → 选已绑定的 M1。奔图云打印**没有公开 API**，开放平台 SDK 需企业资质审核，因此这一步必须由小程序完成，App 只负责交出排版好的 PDF。

## 题目来源与版权边界

- **不抓取、不内置任何市面题库 / 教辅 / 教材原题。** 题目 100% 由 App 内算法生成，或按知识点自编。
- 外部练习网站只借鉴「有哪些题型」这一层规则（填括号、凑十、连加连减、元角分换算、字母顺序等属于题型模式与数学事实），不复制其原题、PDF、图片或版面。
- 速查表只收录不受著作权保护的基础事实与公式，自行整理编排。
- 练习纸的「横条 / 方格 / 英文四线三格」版式思路参考 [namishu/printables](https://github.com/namishu/printables)（MIT）。本项目**未使用其代码、样例 PDF 或内置字体**，全部用 Android Canvas 自绘重新实现；完整 MIT 声明见 [`app/src/main/assets/licenses/NAMISHU_PRINTABLES_LICENSE.txt`](app/src/main/assets/licenses/NAMISHU_PRINTABLES_LICENSE.txt)。田字格、米字格、坐标纸等为通行基础版式，自行编排。
- **v0.5.0 英语 3 题型**：只借鉴 [xckevin/magic-english-buddy](https://github.com/xckevin/magic-english-buddy) 的「单词拼装 / 句子排序 / 选词填空」**题型模式**。该仓库主许可为 **CC BY-NC-SA 4.0**（禁止商用 + ShareAlike 传染），因此其代码、课文、词表、音频、提示词一律不碰；本 App 的单词、句子、语法选项全部自编并按 3–9 年级分级（纸质卷子也用不了它的听音辨图）。
- **v0.5.0 主题识字**：只借鉴 [dangxiaoshi/child-names](https://github.com/dangxiaoshi/child-names) 的「按生活主题分人物 / 物品 / 设施」和「拼音在上、汉字在下」的组织与版式思路。该仓库 README 声称 MIT 却没有 `LICENSE` 文件（GitHub `license=null`）、依赖付费图像 API，且原词表存在多处拼音错误，**不能整站内置**；本 App 的词语与拼音逐条重录校对，田字格与词卡用 Canvas 自绘。
- **v0.7.0 音标 / 语法 / 课本同步**：只收**事实性内容**。音标符号是国际语音学界的通用记音符号（IPA），48 音素的分类与基础例词是公共知识；语法规则（三单加 -s、be 动词三形）是语言事实，说明文字与例句全部自己重写；课本同步只收「清单」——生字与读音、核心词与释义、数学知识点标题，**一条教材课文原文都没有收录**，也没有对应任何一套教材的单元顺序。字形覆盖做过验证：从模拟器拉出系统字体用 fontTools 逐字符查 cmap，确认 ː ɪ ʊ ɑ ɜ ɒ ʃ ʒ θ ð ŋ 全部有字形，再渲染导出的 PDF 复核，避免印出「长短元音不分」的错表。
- 统一规则：**能整站内置的只有明确开源且许可允许商用的**；其余一律转成题型规则 / 自编词库 / 自绘版式。外部网站和仓库只作为入口或思路来源，不打包任何原题、PDF、图片、字体或音频。
- 不打包任何字体文件，中文靠 Android 系统字体回退，PDF 体积保持在几十 KB。

## 技术方案

- Kotlin 2.0.21 + Jetpack Compose (Material3) + AGP 8.5.0，单 Activity，手写 `AppState` 状态容器（不引 Hilt / Room）。
- PDF：`android.graphics.pdf.PdfDocument` 直接绘制，零第三方依赖。排版是两阶段：`FlowLayout` 先算「第几页 / 第几栏 / 哪个 y」，再逐页画卷头、页眉页码、正文、页脚。多栏采用水位均衡填充，不会 20 道题全挤左栏。
- 预览：`PdfRenderer` 把**同一份 PDF 字节**渲染成位图，所见即所得。
- 分享：`FileProvider` + `ACTION_SEND(application/pdf)`。
- 本地存储：`papers.json` / `mistakes.json`，纯本地，无账号、无上传。

## 构建

```bash
# 需要 JDK 17、Android SDK 34
export JAVA_HOME=/opt/homebrew/opt/openjdk@17/libexec/openjdk.jdk/Contents/Home
export ANDROID_HOME=$HOME/Library/Android/sdk
./gradlew :app:assembleRelease
```

产物：`app/build/outputs/apk/release/app-release.apk`（用 debug keystore 签名，方便覆盖安装、数据不丢）。
