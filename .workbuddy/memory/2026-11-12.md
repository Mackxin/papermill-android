### 关键调研结论（已核实，不要再重新查）
- **奔图远程打印无公开 API**：只有「奔图云打印」微信小程序；奔图开放平台 SDK 需企业资质（联系销售→申请→审核）。→ App 只做「生成 PDF + 分享到微信小程序」，不承诺一键云打印。
- **局域网打印不需要 SDK**：M1 支持 AirPrint/Mopria，走 Android `PrintManager` + `PrintDocumentAdapter`。
- **`PrintManager.getPrintServices()` 在公开 SDK 里不存在**（javap 查 android-34 只有 `getPrintJobs` / `print` / `isPrintServiceEnabled`）。探测打印服务改用 `PackageManager.queryIntentServices("android.printservice.PrintService")`，且 Manifest 必须声明 `<queries>`。
- 题库版权：菁优/学科网无开放接口 → 题目只能程序化生成或自编。

### 架构决策
- 版本组合：AGP 8.5.0 + Kotlin 2.0.21 + Compose 1.6.8 + compileSdk 34 / minSdk 26 / jvmTarget 17（本机已验证可编）。
- **不用 Hilt**（本机 Hilt KSP 在 Kotlin 2.0 下解析不到模块自身类）→ 手写 AppContainer（范本：`小白一生app/core/di/ServiceLocator.kt`）。
- 排版引擎两阶段：先 `FlowLayout.layout()` 出 Page 列表（知道总页数），再逐页画 → 才能写「第 x 页 / 共 y 页」。
- 多栏必须「均衡水位填充」，见下.

### 踩过的坑（重要）
- **多栏失衡 bug**：`assignToColumns` 计算目标水位时把「当前栏已占高度」也减掉了，导致目标随题数收缩，20 题被切成 7+13（答案页 4/4/4/8）。
  修法：只减「前面已填满的栏」的累计高度 → `target = (total - filledBefore) / colsLeft`。修好后 10+10、5×4。
- 离线构建缺 `kotlin-stdlib-jdk8:1.8.20` → 首次构建必须联网拉依赖，之后可 `--offline`。
- 本机 git push 走沙箱代理会 502/HTTP2 错误 → 起 Clash Verge 后 `git -c http.proxy=http://127.0.0.1:7897 -c https.proxy=... push`，完事 `pkill -f verge-mihomo`。
- PDF 转 PNG 验证：`sips` 只能转首页；整本用 `osascript -l JavaScript` + PDFKit 的 `thumbnailOfSizeForBox` 逐页导出（qlmanage 在本机沙箱下失败）。

### 第二轮（用户反馈「只有三个按钮，没法选年级科目」后，已完成）
- **教训**：M0 验证页不能当交付物给用户；用户要的是能选年级/科目/题量的完整流程。以后交付前先自问「用户拿它能打印出什么」。
- 删除 `SamplePaper.kt`，MainActivity 换成 `PaperMillRoot` 单 Activity 多页面（出卷/参数/预览/错题本/试卷库/打印帮助）。
- 生成层：`domain/generate/` — Models / WordBank / QuestionGenerator(BaseGenerator+Registry) / MathGenerators(9个) / LanguageScienceGenerators(语文3+英语1+物理1+化学1) / PaperComposer+Templates。
  - 答案由生成过程副产品给出；口算带 `verifyArithmetic` 重新解析算式求值自校验。
  - FNV-1a 偏移量超过 Long.MAX → 必须用 ULong 字面量 `0xcbf29ce484222325UL`，否则 Kotlin 编译报 Value out of range。
- 预览：`PdfPreviewRenderer` 用系统 `PdfRenderer` 把生成的同一份 PDF 字节渲染成 ImageBitmap，真正 WYSIWYG。
- 持久化：`core/store/LocalStore` 用两份 JSON（papers/mistakes），首版没上 Room；支持备份导出/恢复。
- 闭环：预览页勾错题 → 错题本 → 一键错题重练卷（同知识点最多 3 题，练完置 PRACTICED）。
- **踩坑**：语文词表 18 个词却要 30 题，去重后只出 28 题 → 扩词表 + 每种题型 3~4 种题干模板 + UI 明确提示题量不足。
- **踩坑**：ChipGrid 等宽 weight 后 5 个/行仍会让「五年级」换行 → 年级改 4 个/行、chip 水平 padding 13dp→9dp。
- 实测：三年级数学 29 题 4 页（20 道算式答案自动核验全对）、初三物理 4 题带答题横线、三年级语文 30/30 题、系统打印弹框 1/4 页、错题本 3 条 → 重练卷成功。
- release APK 10MB，commit 7d068de 已推送。
