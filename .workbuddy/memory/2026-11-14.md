## 本轮需求
小宝提出：预览时一页还有空白要能加题、支持自定义题目数量、打印支持横屏；
并给了 5 个资源站问能否内置，最终目标是「选择年级 → 找题目 → 打印出完整的一页纸」。

## 关键架构决策
1. **页面几何参数化**：PageGeometry 从 object 常量改成 data class（A4_PORTRAIT 595×842 / A4_LANDSCAPE 842×595）。
   PaperDocument / RenderedPdf 带 PageOrientation；PrintLauncher 用 `MediaSize.ISO_A4.asLandscape()`（javap 确认公开方法存在）。
   PDF 页面尺寸和打印框 MediaSize 必须同时改，否则驱动会二次缩放裁掉题号。
2. **练习纸走独立渲染分支**：PaperSection.grid 非空时 PaperRenderer 直接画「1 页铺满」，
   不套 FlowLayout（流式排版是按题量分页，画不满一页，和目标相反）。
3. **整卷连续流排版（本轮最重要的修复）**：
   旧版每个 section 各调一次 FlowLayout.layout() 再 pages.addAll，导致**每个大题强制另起一页**。
   实测一年级「计算题大全」被印成 7 页 / 99 题。
   改法：所有大题的块合并成一条流，标题 / 需书写过程的题用 FullWidthBlock 占整行；
   FlowLayout 重写成「段 + 贪心最矮栏」模型，支持整宽块落在页中、段内连续分栏、跨页续排。
   答案页单独成流（4 栏、startsOnFirstPage=false），保持另起一页。
4. **预览页加题的硬约束**：probeAppend() 在现有 paper 上追加题并试排，
   `addQuestions` 按 [n, .75n, .5n, .25n, 1] 依次试探，取第一个「不增页」的；
   `fillLastPage` 逐轮保留填充率最高且不增页的一版。加题后同步 counts 与卷头副标题。
5. **自动补题收敛**：旧版 suggestedExtra 不按栏数折算，5 轮把 46 题补到 99 题。
   现在 gain = TYPICAL_QUESTION_H / columns、横版用 410pt 页高、只在 `basePages == 1` 时补、
   MAX_AUTO_EXTRA = 24；预设题量调小（计算题大全 34 题 / 思维小练 25 题）。
   题量不足提示改成「缺口 > 20% 或末页 < 70%」才报，避免少两三题就误报。

## 遗留 / 下轮可考虑
- 不同栏数的 section 现在统一按 bodyColumns 排，主观题用整宽块规避；若将来要「同页内 2 栏 + 3 栏混排」需再扩 FlowLayout。
- 历史卷去重（recentHashes 取 5 张）会让一年级小题型逐渐抽不出新题，连续生成多张同年级卷时题量会缓慢下降。
- 练习纸目前固定 1 页；若用户要「一次打印 5 张田字格」，需要在预览页加份数/多页。

## 追加调研：github.com/xckevin/magic-english-buddy（能否内置）
**结论：不能整站内置，且比之前 5 个站风险更高，别重复调研。**
- 主 LICENSE = **CC BY-NC-SA 4.0**（署名 / 非商业 / 相同方式共享），Copyright (c) 2026 xckevin。
  - NC：App 定位是「做成产品给别人用」，即便当前免费也踩商业目的风险；
  - SA：改编后衍生作品必须同样以 CC BY-NC-SA 分发，会把整个 PaperMill 锁死成非商业项目。
- 技术栈 React 19 + TS + Vite PWA；PaperMill 是 Kotlin + Compose 原生且明确不走 WebView，代码层无法复用。
- 素材 25.3MB / 1721 个 MP3。`public/audio/README.md` 明写「模型许可不替代本仓库内容许可」：
  Kokoro-82M 虽是 Apache-2.0，生成的音频仍受 CC BY-NC-SA 约束；且纯打印 App 用不上音频。
- ECDICT 词典种子是 MIT（© 2025 Linwei），**理论上可单独用**，但必须回上游
  skywind3000/ECDICT 取自原始 CSV，不能从这个仓库拷（这里已改编 + 加课文例句，改编部分受 NC-SA）。
- 可合法借鉴的只有「题型模式」：单词拼装、句子排序、选词填空；
  听音辨图依赖音频，纸质卷不适合。90 篇 L1–L7 课文、成长体系、卡牌、UI 一律不能搬。

## 追加调研：github.com/dangxiaoshi/child-names（儿童识字小报生成器）
**结论：不能整站内置；可借鉴「主题识字词表 + 拼音/汉字双行标签」的版式思路。**
- **许可瑕疵**：README 末尾只写一句「MIT License」，但 `gh api repos/.../license = null`，
  根目录只有 README.md / api-nano-bana-pro.md / index.html / prompt.md / script.js / style.css，
  **没有任何 LICENSE / COPYING / NOTICE 文件**，GitHub 识别不到许可证。
  商用产品的合规扫描会标红；若要正式用其代码，得先请作者补 LICENSE。
  稳妥做法：不碰它的代码与提示词文本，只用不受著作权保护的事实性词汇。
- **技术路线冲突**：纯前端 HTML/JS，调 kie.ai 的 Nano Banana Pro **付费图像 API**，
  用户自填 API Key、联网、10–30s 生成 4K PNG 位图；
  PaperMill 是纯离线、无 Key、矢量文字 PDF。且 AI 生成汉字常写错，教学产品不能印错字。
- 仓库 16KB / 0 stars / 最后推送 2025-12-14，维护不确定。
- **可合法借鉴**：
  * 6 个生活主题（超市 / 医院 / 公园 / 学校 / 动物园 / 交通）按「人物 / 物品 / 设施」分类的思路 ——
    事实性词汇不受保护，但必须**自编重录**：原表拼音有多处错误
    （bái bái hēi 黑板、qiāo qiāo qiāo 跷跷板、jiāo tóng zhì 交通志、shān dìng 隧道、tiān tiān 天桥），
    直接抄会把错拼音印到纸上。
  * 「拼音在上 + 汉字在下」双行标签、A4 竖版、田字格 → 做成主题识字练习纸（一页铺满）。
  * 题型：看拼音写词语（已有 PINYIN 可复用）、主题词语归类、连字成词。

# 2026-11-14 · 卷子 PaperMill v0.5.0（英语专项 + 主题识字）

小宝说「开始」，要求把前面两个仓库调研后攒下的可落地内容一起做完并发新版。

## 落地内容
- 英语 3 题型（`EnglishWorksheetGenerators.kt`）：单词拼装 / 连词成句 / 选词填空；
  `SentenceBank` + `ClozeBank` 全部自编并按 3–9 年级分级，只借鉴 magic-english-buddy 的题型模式。
- 主题识字（`ThemeWords.kt` / `ThemeGenerators.kt`）：6 大生活主题、约 100 词、拼音逐条重录校对；
  3 题型（看拼音写词 / 找不同类 / 归类填空），选项洗牌后答案字母同步换算。
- 主题识字纸 12 张：`GridStyle.THEME_CARD` + 新 `ThemeCardPainter.kt`，
  拼音在上、田字格在下，按词数算行数再平分整页高度；`showThemeWords` 切描红 / 默写。
  `PracticeData.themeSheets` 生成 6 主题 × 2 练法；`PracticeSheet.footer` 单独标版权边界。
- 首页「04 本版新增」两张卡（`AppState.generateForSubject` 自动切科目再出卷），
  打印纸页第三组 12 张识字纸；预设列表放开到 8 张。

## 实测发现并修掉的问题（重要，别再踩）
1. **卷头题数印错**：`PaperAssembler` 直接用 spec.subtitle，请求 37 题只生成 23 题时纸上印「共 37 题」。
   → 改为按 `paper.questions.size` 重算自动副标题，自定义副标题原样保留。
2. **单栏题型仍被塞进半栏**：PaperRenderer 整卷统一 `bodyColumns = maxOf(...)`，
   只判断 `answerLines > 0` 才包 FullWidthBlock；PaperComposer 里设 `columns=1` 根本没用。
   → 改成 `forceFullWidth = answerLines > 0 || section.columns <= 1`；
   英语 CLOZE/SENTENCE_ORDER 与 THEME_SORT/THEME_GROUP 的 `columns` 都改为 1。
3. **自动补题单栏场景整轮回退**：suggestedExtra 按全局 columns=2 估算，
   一次补 16 道单栏题顶到第二页 → 触发「不增页」break 回退，末页只剩 65%。
   → `suggestedExtra(ratio, fillType)` 按实际补的题型栏数折算；每轮只走估算量 80%，多轮逼近；
   `pickFillType` 跳过「请求数 > 实际生成数」的已抽干题型；扩充三年级自编句库与语法题库。
4. **同页连出两次同一个词**：两个 Theme 生成器加 `lastWord`，重抽最多 5 次避开上一题。
5. 低年级句库 / 题库扩容后「可用题量不足」误报消失。
