# 2026-11-14 · 卷子 PaperMill v0.4.0

## 本轮需求
小宝提出：预览时一页还有空白要能加题、支持自定义题目数量、打印支持横屏；
并给了 5 个资源站问能否内置，最终目标是「选择年级 → 找题目 → 打印出完整的一页纸」。

| 站点 | 结论 | 落地 |
| --- | --- | --- |
| github.com/namishu/printables | ✅ 代码 / 原创文档 / 模板设计 MIT（字体除外） | 只借鉴横条 / 方格 / 英文四线三格版式分类，Canvas 自绘重实现；LICENSE 全文放 assets/licenses/NAMISHU_PRINTABLES_LICENSE.txt |

## 关键架构决策
1. **页面几何参数化**：PageGeometry 从 object 常量改成 data class（A4_PORTRAIT 595×842 / A4_LANDSCAPE 842×595）。
   PaperDocument / RenderedPdf 带 PageOrientation；PrintLauncher 用 `MediaSize.ISO_A4.asLandscape()`（javap 确认公开方法存在）。
   PDF 页面尺寸和打印框 MediaSize 必须同时改，否则驱动会二次缩放裁掉题号。
2. **练习纸走独立渲染分支**：PaperSection.grid 非空时 PaperRenderer 直接画「1 页铺满」，
   不套 FlowLayout（流式排版是按题量分页，画不满一页，和目标相反）。
3. **整卷连续流排版（本轮最重要的修复）**：
   旧版每个 section 各调一次 FlowLayout.layout() 再 pages.addAll，导致**每个大题强制另起一页**。
   实测一年级「计算题大全」被印成 7 页 / 99 题。
   改法：所有大题的块合并成一条流，标题 / 需书写过程的题用 FullWidthBlock 占整行；
   FlowLayout 重写成「段 + 贪心最矮栏」模型，支持整宽块落在页中、段内连续分栏、跨页续排。
   答案页单独成流（4 栏、startsOnFirstPage=false），保持另起一页。
4. **预览页加题的硬约束**：probeAppend() 在现有 paper 上追加题并试排，
   `addQuestions` 按 [n, .75n, .5n, .25n, 1] 依次试探，取第一个「不增页」的；
   `fillLastPage` 逐轮保留填充率最高且不增页的一版。加题后同步 counts 与卷头副标题。
5. **自动补题收敛**：旧版 suggestedExtra 不按栏数折算，5 轮把 46 题补到 99 题。
   现在 gain = TYPICAL_QUESTION_H / columns、横版用 410pt 页高、只在 `basePages == 1` 时补、
   MAX_AUTO_EXTRA = 24；预设题量调小（计算题大全 34 题 / 思维小练 25 题）。
   题量不足提示改成「缺口 > 20% 或末页 < 70%」才报，避免少两三题就误报。

## 遗留 / 下轮可考虑
- 不同栏数的 section 现在统一按 bodyColumns 排，主观题用整宽块规避；若将来要「同页内 2 栏 + 3 栏混排」需再扩 FlowLayout。
- 历史卷去重（recentHashes 取 5 张）会让一年级小题型逐渐抽不出新题，连续生成多张同年级卷时题量会缓慢下降。
- 练习纸目前固定 1 页；若用户要「一次打印 5 张田字格」，需要在预览页加份数/多页。

## 追加调研：github.com/xckevin/magic-english-buddy（能否内置）
**结论：不能整站内置，且比之前 5 个站风险更高，别重复调研。**
- 主 LICENSE = **CC BY-NC-SA 4.0**（署名 / 非商业 / 相同方式共享），Copyright (c) 2026 xckevin。
  - NC：App 定位是「做成产品给别人用」，即便当前免费也踩商业目的风险；
  - SA：改编后衍生作品必须同样以 CC BY-NC-SA 分发，会把整个 PaperMill 锁死成非商业项目。
- 技术栈 React 19 + TS + Vite PWA；PaperMill 是 Kotlin + Compose 原生且明确不走 WebView，代码层无法复用。
- 素材 25.3MB / 1721 个 MP3。`public/audio/README.md` 明写「模型许可不替代本仓库内容许可」：
  Kokoro-82M 虽是 Apache-2.0，生成的音频仍受 CC BY-NC-SA 约束；且纯打印 App 用不上音频。
- ECDICT 词典种子是 MIT（© 2025 Linwei），**理论上可单独用**，但必须回上游
  skywind3000/ECDICT 取自原始 CSV，不能从这个仓库拷（这里已改编 + 加课文例句，改编部分受 NC-SA）。
- 可合法借鉴的只有「题型模式」：单词拼装、句子排序、选词填空；
  听音辨图依赖音频，纸质卷不适合。90 篇 L1–L7 课文、成长体系、卡牌、UI 一律不能搬。
