## 五处卷面问题（用户截图报的）

用户四句话五个问题：① 改题后答案改不了，「或者你可以自己知道答案」；② 一年级科学题干字太多、孩子不识字；③ 得分后三个方框不要；④ 17/25 为什么换行；⑤ 左下角那句「自定义」的东西不想要。

### ① 改题同时改答案（本轮最大一件）
- `renderer.js`：答案页的题带上 `uid`，块打 `isAnswer`；绘制时答案块进 `page.answers`（节点标 `p.a`，正文是 `p.q`），新增导出 `repaintAnswer(pages, qid, text)`，按原 slot 重画、不重排。
- `paper.js`：原地编辑框加「答案」行（`inline-ans`），失焦只在「焦点离开整个编辑框」时提交（点到答案框不能把框关掉，用 `box.contains(e.relatedTarget)`）。
- `app.js`：`commitInlineEdit(stem, answer)`；`autoAnswer` 只认 `CALC_TYPES` 里的纯算式，`evalExpr` 是手写的两栈四则运算（不走 eval）；除不尽返回 null（有余数除法）；用户手改过答案不覆盖；改完 `syncPaper()`。
- 面板里也加了「答案」输入（只重画答案页那一格）。

### ② 低年级科学
一二年级科学大题说明加一句「低年级科学以观察和口头表达为主：请家长读题，孩子口头作答即可。」（web composer + `PaperComposer.LOW_GRADE_SCIENCE_NOTE`）。没有硬造拼音注音：题库里 36 道一年级题的生字跨了「植/察/舌/尝/麻/雀」这些，手写拼音表容易出错，宁可把作答方式改成口头。

## v0.23.0 知识点专项：搬 shijuan.on2on.cn 的 15 个数学知识点

**来源**：用户给了 https://shijuan.on2on.cn/index.html 说「这个网站里面的全部内置到题库」。
站点结构：首页是卷子下载列表（人教版/苏教版/教科版/统编版 × 年级 × 科目 × 卷型），
真正能搬的是 `/math-nav.html`「知识点导航」——15 个数学知识点，每个一页、只出一种算式、题量 5~50。
逐页抓了 `/shijuan/js/shijuan-math-item-*.js`，把 generate() 的范围与条件原样移植。

**15 个知识点**（`web/js/core/models.js` MATH_POINTS ↔ `Models.kt` MathPoint，逐条对应）
一：10以内数的比较 / 加法 / 减法、20以内退位减法（个位不够减）、100以内不进退位加减法
二：100以内进退位加减法（必进位/必退位）、表内乘法、表内除法、有余数的除法、乘加乘减
三：万以内加减法（笔算）、多位数乘一位数、长方形正方形周长、分数简单加减法（要约分）、两位数乘两位数

**设计决定**
- 知识点是**一等维度**，不是新题型：`spec.points` 非空 = 专项卷，`counts` 整块不参与，
  一个知识点一道大题、大题名直接用知识点名（「一、表内乘法」而不是「一、口算」）。
- 渲染复用已有题型：ORAL / COMPARE / VERTICAL（带「用竖式计算」说明）/ WORD_PROBLEM / FRACTION。
- 自动跟着走：科目切数学、年级取所选知识点的最大年级、标题 `小学 · 二年级 · 表内乘法专项`。
- 题量 10/20/30/50；每个知识点独立种子（`sectionSeed(seed, 700+i)`），改一个不洗别人的牌。
- 界面必须说边界：勾了知识点后「题型与题量」区换成「本卷不生效」+ 一键清空。

**踩坑**
- e2e 数题量不能数 DOM 节点：一道题在 DOM 里是**两个** `[data-q]`（题号 + 题干），按 `dataset.q` 去重。
- 之前用例留下的自编题会追加进专项卷，导致题量对不上 → 用例开头 `frame.contentWindow.localStorage.removeItem` 重开。
- App 侧 `pointCount` 的 private setter 与自写 `setPointCount` JVM 签名冲突，改名 `choosePointCount`。

**验证**
- 网页 `e2e.html` 37 → **39 项全绿**；node 里逐个知识点跑 50 题校验范围/答案/约分。
- 单文件版 3.28 MB 重打，`file://` 实测：19 个 chip、点表内乘法卷头变「表内乘法专项」、20 题、2 页、零报错。

  一、表内乘法 40 分 20 题全是乘法；点两位数乘两位数 → 三个大题名 + 「用竖式计算」说明 + 每题 3 条书写线。
