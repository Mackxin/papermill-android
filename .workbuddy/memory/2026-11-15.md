# v0.10.2 按钮高度 46dp → 40dp

## 起因
用户 11-14 提「系统打印、保存、分享 这三个按钮的框，不要那么高，你看一下排版」。
量出来：三个按钮宽 138 / 106 / 106dp，高 46dp —— 窄而厚，像三块立着的砖；
底部操作条 54dp 也跟着厚。

## 改法
- `PaperDimens` 新增 `ActionBtnH = 40.dp`，`ActionBarH` 54 → 48dp
- `PrimaryButton` / `SecondaryButton` 的高度改用它（全 App 唯一定义处，改两行覆盖所有页面）
- `StickyBar` 上下留白 5dp → 4dp

## 踩坑
1. **uiautomator 的 bounds 量不出按钮真实高度**：改前改后都报 126px，
   因为 Compose 的 `clickable` 会把语义可点击区扩到 48dp 最小触摸区。
   要量真实高度必须走像素：精确匹配填充色（次按钮 #F2F3F9、主按钮 B-R>30），
   实测 105px = 40.0dp 才算数。
2. **次按钮的 #F2F3F9 和操作条底 #F5F6FB 只差 3/3/2**，容差 ±3 会把整条 bar 算进去，
   必须精确相等匹配。
3. `sed -i ''` 在 macOS 上带多表达式要用 `-e`，直接拼两个 `s///` 会当成文件名报错。

## 实测
按钮着色区 105px = 40.0dp（420dpi）；首页 / 自由组合 / 预览三页复查，
文字居中无裁切，与 dock 间距协调。APK 11,341,783 字节。
