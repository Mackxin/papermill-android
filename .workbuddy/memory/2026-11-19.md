## v0.26.0 · App 内下载安装 + 真题只留有答案 + 名卷库退场

**用户三个要求（原话）**
1. 「下载更新，直接在 app 内下载，下载完直接调用系统来安装」
2. 「没有答案的话那不行，没有答案的话从真题库去掉吧，内置的题都要有答案的」
3. 「既然已经下载了，那么名卷那里的是不是可以去掉了」

**结果**
- App 内更新跑通：检查 → 下载（进度条）→ 授权页（首次）→ 安装器 → 版本变 0.26.0。
- 题库 13596 → **3615 道，全部带答案**（语 1641 / 数 1689 / 科 180 / 英 105）。
- 名卷库两端删除（`PaperLibrary.kt`、`assets/papers/library.json` 176KB、web 页面与 2 条 e2e）。
- 题库 3MB → 830KB；单文件 6.4MB → 4.27MB；APK 3.0MB → 2.35MB；e2e 45 → 43 项全绿。
- 发布 release v0.26.0（`gh release create`，APK 已上传可覆盖更新）。
- 提交 2f93b12 已推送到 Mackxin/papermill-android。

**关键技术点**
- GitHub 资产地址 302 到 objects.githubusercontent.com，跨域跳转 HttpURLConnection 默认不跟，
  要 `instanceFollowRedirects=false` + 手动跟 `Location`（最多 5 跳）。
- 装本地 APK：`FileProvider.getUriForFile` → `ACTION_VIEW` + `setDataAndType(application/vnd.android.package-archive)`
  + `FLAG_GRANT_READ_URI_PERMISSION`（少了安装器打不开 content://）。
  FileProvider 里 `<cache-path path="."/>` 已覆盖 cacheDir，不用再改 xml。
- Android 8+ 必须 `canRequestPackageInstalls()` 检查，没授权跳 `ACTION_MANAGE_UNKNOWN_APP_SOURCES`；
  清单要 `REQUEST_INSTALL_PACKAGES`。
- 安装包按版本号命名存 cacheDir，App 被回收后靠 `cachedUpdateApk()` 从磁盘找回来，
  否则用户从授权页回来要重下 3MB；按版本号命名能避免「点 v0.27 装成 v0.26」。
- 答案解析：`一． B A B A A C` 这种「中文序号 + 空格序列」原来被当成大题标题吃掉，
  要在标题分支里判断 tail 是不是一串答案（`SEC_KW` 不含才算）；切序号时 `(?<![\d.])`
  排除小数点，否则 `1.18.33 47` 会在 `18.` 处再切一刀。
- 答案序列只在「数量完全等于该大题小题数」时按序填 —— 错配的答案比没答案更糟。
- 答案校验必须做，否则英语整段错位会给出「Where is the cinema? → bus」。
  剥分值 `（N分）` 后再判断（`B（3分）` 是正确答案）。

**踩坑**
- 按分隔线删「名卷库」页面时，把紧跟其后的 `TextbookScreen`（课本页 205 行）一起删了，
  编译报 `Unresolved reference: TextbookScreen`。教训：删代码段要先确认「下一个分隔线」
  之间还有没有别的函数，`awk` 列出该区间所有 `// ---` 再动手。
- `sed -i ''` 在本机 zsh 下报 "No such file or directory"，改用 Python 改文件。
- 环境变量里有 `HTTP_PROXY=http://127.0.0.1:49800`（坏的，502），git push 必须
  `env -u *_proxy` + `-c http.proxy=http://127.0.0.1:7897`（Clash 混合端口）。
- 模拟器验证前要 `adb uninstall` 再装：App 会 `restoreSessionOnce` 恢复上次预览的卷子，
  不清数据会看到旧题库生成的答案（出现过「三年级数学卷答案里冒出 banana」的假警报）。
- 模拟器底栏坐标：1080x2400，dock 在 y=2260（不是 2362），用 `uiautomator dump` 取 bounds 最准。

**新增工具**
- `tools/rebuild.py`：切题 → 题库体检（空池点名）→ 重建单文件，一条命令；
  `--audit` 只体检。退出码 1 表示有空池。

## v0.27.0：幼小衔接 + 真题抽查 + 三处修正

### 新增「学前」一档（g=0）
- `Subject.availableFor(0)`：只放 MATH / CHINESE；`GradeProfiles` 加 `GradeProfile(0, 20, 0, 0, true, true, 0, 1)`（数域 20、允许进位退位）
- `PaperKind.minGrade` 默认 1 → 0（竞赛/奥数写回 1），否则学前点不了任何卷型
- 8 个生成器放开 `minGrade = 0`：FILL_BLANK / MAKE_TEN / COMPARE / NUMBER_PATTERN / COUNTING（数学）+ PINYIN / HANZI / DICTATION（语文）
- `bound(0)` 落到 `grade <= 1 → 10`，天然是学前难度，不用改生成逻辑
- `WordBank.chineseFor` 加 `coerceAtLeast(1)`：否则 g=0 词表为空、语文卷一道题都出不来
- 题量折半：`defaultSpec` 里 `counts.replaceAll { (n/2).coerceAtLeast(4) }`；`forSelection` 预设卡同理（每型至少 3）
- `gradeLabel(0) = "学前"` 而不是"幼小衔接"—— 六列 grid 里四个字会被截成「幼小衔」，全称放 SectionLabel 副标题
- `autoTitle` 里 stage 与 grade 撞名时只留一个（原来印出「学前 · 学前」）

### 幼小衔接为什么不做「真题内置」
调研了人人文库 / 夜雨聆风 / 4mf / kiddosheet / tlsbooks：全是教辅练习册，一律「仅限个人学习、禁止再分发」；幼儿园没有统一考试，压根不存在「真题」这个概念。拼音表、笔画数、20 以内加减属于公共知识，程序生成更准。

### 修掉的三个 bug（都是复查时撞见的）
1. **真题开关开着切到没真题的年级 → 0 页空卷**。`PdfRenderer` 报 "file not in PDF format or corrupted"，用户完全猜不到病因是「这个年级没真题」。修法：`useExam` 加「题库里真有这个年级+科目+大类的题」；`compose` 末尾 `sections.isEmpty()` 直接抛人话
2. **真题模式说「已经排满」**：真题不走 counts 补题，`autoFillPage` 分支却说"不需要再加"，纸上明明空着
3. **补满堆题**：`pickFillType` 原来 `return last`（永远最后一个大类），33 题里 18 道都成了找规律。改成 `minWithOrNull(compareBy(have[it], answerLines))` 谁少补谁

### 真题库
- 3441 道（语 1567 / 数 1689 / 科 169 / 英 16），**英语从 105 砍到 16**
- 英语只留「有完整选项 + 答案能自证」的选择题：英语卷一半听力、笔试多连线看图，能切的里三成答案错配。宁可 16 道全对
- 新增五道闸门：字母串答案（AEG/BCFJ=匹配题）、圈号序列答案但题干无圈号、填空配整句答案（`I want ____(play)`→`The king likes…`）、答案 A~D 无选项、题干粘大题标题
- 解析修复：`QNO_PAREN_RE` 认 `( )1.` 前缀（63 份英语卷原本只 9 份切得出题）；`split_options` 的 `\s` 改 `\s*`（`A.an B.a` 点后无空格）
- `questions.json` 顶层加 `sources: {id: 卷名}`，题里仍只存 id；`ExamQuestion` 加 `source` / `sourceTitle`
- `PaperComposer.pickSpread()`：按来源分组 → 组间打乱 → 组内打乱 → 轮转各出 1 道

### 抽查页
`ExamSampleDialog`：挂在根节点（跟批改面板一样），随机 20 道，题干+答案+出处并排，可「换一批」。入口在真题卡片里（`pool > 0` 时显示）。

### 验证
- e2e 25/25 全绿（`web/e2e.html`，用 chrome-for-testing --headless --dump-dom 跑）
- 学前实测：数学 33 题 2 页 88%；语文拼音题 20 道答案全对（西瓜/小鸡/汽车/田野，声调准确）
- release APK 2.3MB 装机验过，已发 GitHub release v0.27.0
